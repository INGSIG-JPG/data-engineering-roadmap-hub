# Evaluación Práctica L2: SQL Avanzado y Funciones Analíticas

## Requisitos de Entrega
Escribir un script SQL que resuelva la consulta del problema y entregar el plan de ejecución (`EXPLAIN`).

## Desafío
Dado un histórico de transacciones, calcula el promedio móvil de 7 días (*7-day moving average*) por cliente, identificando desviaciones superiores al 20% sobre el promedio general.
