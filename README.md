### MÓDULO 1: Manipulación de Datos Masivos Numéricos (NumPy)
> **Fuente de Aprendizaje**: *GCI World UTokyo (Session 02)*

* **Concepto Teórico**: La *vectorización* procesa grandes arreglos de datos en paralelo en memoria C, evitando los bucles `for` lentos de Python.
* **Aplicación Minera / Industrial**: Filtrar lecturas de gas metano o temperatura de miles de sensores en un tajo abierto instantáneamente.
* **Implementación en Código**:
  ```python
  import numpy as np

  # Simulación de lecturas de temperatura de 6 sensores en planta (°C)
  temperaturas = np.array([45, 88, 102, 35, 95, 110])

  # FILTRO DE SEGURIDAD (HW1 UTokyo): Extraer lecturas > 80°C Y que sean impares
  alertas_criticas = temperaturas[(temperaturas > 80) & (temperaturas % 2 != 0)]
  print("Alertas críticas registradas:", alertas_criticas) # [95]
1. **Teoría de la Carga Cognitiva (Sweller, 1988)**: Se divide la complejidad técnica en fragmentos pequeños (micro-aprendizaje diario) para no saturar la memoria de trabajo.
2. **Andamiaje Cognitivo (Vygotsky, 1978)**: Aprendizaje de Cero a Producción, donde cada concepto teórico se acompaña de un ejemplo ejecutable y una autoevaluación.
3. **Transferencia Analógica Interdominio (Gentner, 1983)**: Conexión entre la gestión de plantas físicas (seguridad industrial, minería) y el procesamiento de fluidos digitales (datos).
