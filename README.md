## 🏆 Niveles de Competencia (Framework L0–L3)

- **L0 — Sin Conocimiento:** No se ha estudiado el concepto.

- **L2 — Intermedio (Independiente):** Capaz de resolver ejercicios y construir pipelines sin consultar guías paso a paso.

## 🛡️ Quality Gates para Proyectos (`17_portfolio/`)

Un proyecto no pasa a `17_portfolio/` por el solo hecho de funcionar. Debe cumplir con el siguiente checklist obligatorio:
- [ ] **Arquitectura:** Diagrama claro y selección justificada de tecnologías.
- [ ] **Ingesta & Transformación:** Manejo de excepciones, validación de esquema y tipos.
- [ ] **Calidad de Datos:** Tests automatizados (ej. Great Expectations / pytest).
- [ ] **Contenerización:** `Dockerfile` y `docker-compose.yml` funcionales.
- [ ] **Documentación:** `README.md` profesional con instrucciones de reproducción paso a paso.
