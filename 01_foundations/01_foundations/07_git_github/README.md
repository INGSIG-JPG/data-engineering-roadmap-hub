### Pregunta
¿Qué diferencia hay entre `git fetch` y `git pull` a nivel de árbol de commits?

**Mi respuesta:**
<!-- Escribe tu respuesta aquí -->

<details><summary>🔎 Ver solución</summary>

`git fetch` descarga los commits, ramas y tags del repositorio remoto sin alterar tu árbol de trabajo local. `git pull` realiza un `git fetch` e inmediatamente ejecuta un `git merge` para integrar los cambios remotos en tu rama actual.
