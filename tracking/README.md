# Tracking

Sistema estructurado para registrar el progreso del aprendizaje y las competencias.

## Archivos

* `courses.csv` — progreso de cursos.
* `competencies.csv` — competencias y nivel.
* `assessments.csv` — evaluaciones.
* `projects.csv` — proyectos.
* `spaced_review.csv` — repasos espaciados.

## Principio

Las métricas deben representar evidencia real.

No se deben introducir porcentajes de progreso que no correspondan a resultados registrados.
