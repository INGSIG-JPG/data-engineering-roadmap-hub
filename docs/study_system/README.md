# Study System

## Propósito

Definir el método utilizado para estudiar, practicar, recuperar, evaluar y consolidar conocimientos de Data Engineering.

## Principios

* Active Recall
* Spaced Repetition
* Deliberate Practice
* Interleaving
* Elaborative Encoding
* Problem-Based Learning
* Project-Based Learning
* Feedback
* Metacognition
* Transfer Practice
* Continuous Improvement

## Ciclo

```text
Aprender
→ recordar
→ practicar
→ aplicar
→ evaluar
→ detectar errores
→ corregir
→ repasar
→ transferir
```

## Regla de independencia

Antes de solicitar ayuda externa:

1. Intentar resolver el problema.
2. Revisar documentación.
3. Identificar exactamente dónde está el problema.
4. Solicitar una pista si es necesario.
5. Rehacer el ejercicio sin ayuda.

## Repaso

Cada competencia tendrá un sistema de revisión progresiva:

R0 → R1 → R3 → R7 → R14 → R30 → R60

Si el conocimiento falla durante una revisión, se registra el error y se ajusta el intervalo.

## Evaluación

El progreso se medirá mediante:

* recuperación de conocimientos;
* comprensión;
* práctica;
* problemas nuevos;
* debugging;
* casos aplicados;
* explicación técnica;
* proyectos.

## Principio fundamental

El objetivo no es completar plataformas.

El objetivo es desarrollar y demostrar competencias de Data Engineering.
