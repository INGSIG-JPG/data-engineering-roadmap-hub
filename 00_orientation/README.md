## Propósito

Este módulo define cómo utilizar el repositorio como sistema personal de aprendizaje, evaluación, práctica y mejora continua para la transición hacia Data Engineering.

## Objetivos

* Comprender cómo utilizar el repositorio.
* Definir el método de estudio.
* Registrar el progreso.
* Diferenciar aprendizaje de competencia.
* Utilizar recuperación activa.
* Aplicar repetición espaciada.
* Registrar errores y corregirlos.
* Evaluar la transferencia del conocimiento.
* Construir evidencia profesional.

# 🧭 Orientation & Learning System

Este módulo establece el protocolo de aprendizaje, las reglas de estudio y la metodología científica aplicada en todo el repositorio.

## 🎯 Reglas del Sistema
1. **Doble Reloj:** El avance en un curso (`courses/`) no equivale a dominar la competencia (`tracking/competencies.csv`).
2. **Active Recall Primero:** Antes de revisar la solución de cualquier tema, debes escribir tu respuesta en la caja de prueba.
3. **Cero Tolerancia al Olvido:** Todo tema estudiado entra en el ciclo de Repetición Espaciada ($R_0 \to R_1 \to R_3 \to R_7 \to R_{14} \to R_{30} \to R_{60}$).
4. **Error es Dato:** Todo error conceptual o práctico relevante genera un registro en `16_learning_log/ERR-XXX.md`.

## 🔄 Flujo de Trabajo Diario
1. Consultar `tracking/spaced_repetition.csv` para ver los repasos del día.
2. Estudiar el tema activo en el módulo correspondiente.
3. Resolver el Active Recall Test sin consultar apuntes.
4. Actualizar el estado en `tracking/competencies.csv`.
