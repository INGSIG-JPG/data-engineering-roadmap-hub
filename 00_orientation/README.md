# 00 — Orientation

## Propósito

Este módulo define cómo utilizar el repositorio como sistema personal de aprendizaje, evaluación, práctica y mejora continua para la transición hacia Data Engineering.

## Objetivos

* Comprender cómo utilizar el repositorio.
* Definir el método de estudio.
* Registrar el progreso.
* Diferenciar aprendizaje de competencia.
* Utilizar recuperación activa.
* Aplicar repetición espaciada.
* Registrar errores y corregirlos.
* Evaluar la transferencia del conocimiento.
* Construir evidencia profesional.

## Ciclo de aprendizaje

```text

```

## Niveles de competencia

| Nivel | Significado |
| ----- | ----------- |
| L0    | Exposición  |
| L1    | Comprensión |
| L2    | Aplicación  |
| L3    | Competencia |

### Regla

Completar un curso no significa automáticamente dominar una competencia.

La competencia debe demostrarse mediante evidencia independiente.

## Evidencias

* Código
* Ejercicios
* Evaluaciones
* Proyectos
* Debugging
* Documentación
* Explicación técnica
* Problemas nuevos
* Casos aplicados

## Cursos externos

Los cursos y aplicaciones se registran independientemente del currículo permanente.

La función del repositorio es integrar y comprobar lo aprendido en:

* Coursera IBM Data Engineering
* DataTalksClub
* GCI UTokyo
* freeCodeCamp
* SoloLearn
* Select Data
* Cody y herramientas de IA

## Principio

Los cursos proporcionan contenido y práctica.

El repositorio proporciona:

**integración + práctica adicional + evaluación + transferencia + evidencia + mejora continua.**
